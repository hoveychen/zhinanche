# 0003：界面外壳统一成一套设计语言（暖色浅底）

- **状态：** 已采纳（老板选的方向「暖色浅底统一」，具体数值是子任务定的，可以再改）。
- **日期：** 2026-10-21

## 问题

和参考项目 leibniz-stepped-reckoner 并排看，差距在界面外壳，不在 3D：它整套只有一种设计语言（一套线性图标，统一的圆角、描边、字号，控件收进舞台底部的悬浮工具栏和右上角一组小按钮）。我们混了五六种：米色仿纸面板、青色顶栏、凸起的红色和米色按钮、白色胶囊按钮、木框拟物罗盘、绿/红状态标签；按钮散在舞台四周；图标有的有有的没有；楷体大标题像绘本。

## 决定

保留宣纸米色和朱红（中国风的气质不丢，也不改深色），但外壳的每一样东西都从 `css/style.css` 开头的 token 里取值，不再各自挑颜色、圆角、阴影和字号。

### 颜色：纸、墨、一个强调色

| token | 值 | 用途 |
|---|---|---|
| `--paper` / `--paper-2` / `--paper-3` | `#fbf8f1` / `#f4eee3` / `#e9dfcd` | 页面和面板 / 顶栏、翻页条、分段按钮的槽 / 按下、空的进度槽 |
| `--surface` / `--glass` | `#fffdf9` / 同色 90% 不透明 + 模糊 | 面板上的卡片和按钮 / 浮在 3D 上的卡片 |
| `--ink` / `--ink-2` | `#2b2620` / `#6a5d4f` | 正文 / 次要文字、小标题 |
| `--umber`（墨褐）| `#7a4a36` | 墨里带一点红：首页和课件的小标题（「一千年前的齿轮机器」「第三课」）、课号方块的字、「第六课 →」、「让它出错试试」的标题和图标。它们是标签，不是按钮，所以不用朱红 |
| `--line` / `--line-2` | `#e4d9c6` / `#cdbc9e` | 细线、卡片边 / 按钮边、开关槽 |
| `--accent`（朱红）| `#c8361f`，文字用 `--accent-ink` `#a42914`，浅底 `--accent-soft` | **只有两个意思**：「按这个」（主按钮）和「这个开着」（按下的分段、开着的开关、画路线中、看齿轮中、暂停中、进度条的当前格）。小标题、课号、链接、任务卡的边、课文里的加粗字都不用它：课号方块是纸底墨褐字，任务卡是 `--line-2` 边，加粗字是 `--ink`，走过的进度格是偏墨的灰 |
| `--ok` | `#2f8a57` | **只有一个意思**：做对了 / 指着正南 |
| `--left` / `--right` | 蓝 / 橙 | 左轮、右轮，是数据颜色，不是界面颜色 |

去掉了：青色顶栏和青色标题（石青 `--shiqing`）、木纹边框、按钮底部的凸起阴影、黑底的「停住了」。

### 形状

- 圆角三级：`--r-s` 8px（小标签、课号方块、印章、3D 上的字签）、`--r-m` 12px（按钮、图片）、`--r-l` 16px（卡片、浮动条，包括弹出的零件名字）。套在槽里的分段按钮用 `--r-m` 减去槽的 3px 内边距，内外圆角才同心。竖放和横放的手机上，浮在 3D 上的卡片（表盘、两个浮动条、提示）收一级到 `--r-m`，卡片小了圆角也跟着小。
- 阴影：`--sh-1`（面板里被按下的分段、开关的钮、钉在 3D 上的字签）、`--sh-2`（浮在 3D 上的卡片和浮动条）、`--sh-sheet`（竖屏和横放手机上从底下拉上来的面板，阴影朝上）。面板里的卡片不加阴影，只用 1px 的 `--line` 边。3D 上的字签不算卡片：它们小、多、跟着零件动，用 `--r-s` 和 `--sh-1`，免得一片厚阴影糊在模型上。
- 描边一律 1px。

### 字

- 一种无衬线读所有字；楷体只留给名字：顶栏的「指南车」和首页大标题。课题、首页问句、表盘方位字、课号都改成无衬线粗体。
- 字号阶梯（token `--fs-*`）：14 `xs`（单位、图注、页脚）/ 16 `s`（次要文字、小标题、HUD 上的字）/ 18 `m`（按钮、界面文字、问题、卡片标题）/ 20 `l`（课文）/ 24 `lead`（首页 3D 上那句话、里程表的大数字）/ 28 `xl`（面板标题）/ 48 `2xl`（首页标题）。桌面上的规则只用这些 token。
- 平板和手机的 media 块里可以「收半级」：15 / 17 / 19 / 22 / 26 / 34 / 40，各是上一级 token 往下收一点（比如课文 20 → 平板 19、横放手机 17）。这些是前几轮为平板和手机逐个调过、保证不切字的，不再各自发明别的数。手机上 HUD 和界面上的字不小于 14px，课文不小于 17px。
- 不在阶梯里的只有两样：名字（顶栏「指南车」和印章「南」，随屏幕 26/24/22 和 23/21/19）和表盘 SVG 里的方位字（SVG 自己的单位，随表盘一起缩放）。
- 课文从 22px 收到 20px：克制，但 9–12 岁的孩子在平板上一臂远仍读得清。

### 间距和尺寸

- 间距阶梯 4 / 8 / 12 / 16 / 24 / 32。
- 触屏目标 `--tap` 48px（横放的手机除外，它竖向只有 390px 左右，保持原来的 44px）。方向键 `--pad-key` 56px，平板 52px，手机 48px。
- 图标 22px，方向键 28px。

### 图标：Tabler Icons（outline）

一套开源线性图标，MIT 许可，2px 线宽，和文字同色（`currentColor`）。`pnpm vendor` 从 npm 包 `@tabler/icons` 只取用到的二十来个，写成 `vendor/tabler-icons/icons.js`；`js/app/icons.js` 的 `icon(name)` 把它们变成 `<svg>`。不走 CDN。原来手画的 SVG（暂停、播放、链接、齿轮、铅笔、箭头、往下看）全部换掉。

选 Tabler 不选参考项目用的 Material Symbols：Material 的图标是填充字形风格，和我们的细线卡片不搭；Tabler 的圆头细线更像毛笔描过的线稿，也有我们要的「方向键」大箭头和「齿轮」。MIT 的许可证文本仓库里本来就有。

### 舞台上的东西：一种卡片，两个浮动条

- **卡片**：表盘、里程表、停住了、画路线提示、步数、首页那句话、拖一拖、点到零件的名字，全部是同一种 `--glass` 卡片（`--r-l`、1px `--line`、`--sh-2`、背后模糊）。
- **角落按钮（右上）**：暂停 + 复制链接（只在自己开时）收进一个小条。手机上只留图标（暂停、链接的图形孩子认得），名字留在无障碍名称和提示里。复制链接按钮按「复制链接」「已复制」中长的那个定宽，点了不跳。
- **驾驶条（右下）**：看齿轮、画路线、方向键收进一个条。看齿轮和画路线**在任何屏幕上都带字**（手机上图标在上、字在下，和方向键同宽，英文长了就折两行）：孩子读的是字，开着看齿轮时字变成「回到车后 / Back out」，告诉他怎么回去。看齿轮的图标是放大镜（进去放大、出来缩小），不用齿轮：齿轮在所有 App 里都是「设置」。方向键改成键盘上的倒 T 形（上一行「前进」，下一行「左拐 后退 右拐」），比原来的十字少一行高，遮的 3D 少。一步只显示它用到的按钮，一个都不用就整条不显示。
- **表盘**：去掉木框，变成卡片里的一个平面罗盘。下面一句话是一个胶囊：指着正南是浅绿底深绿字加绿点；偏了整块变成实心朱红、白字，卡片边也变朱红（第六课「出错」那一刻要扎眼）。
- **里程表**：桌面和课件里展开（两根条 + 差多少）；平板和手机上自由驾驶时默认折叠，折叠后只剩两个数（手机上左右轮上下两行），不留空管子，点一下展开。
- **分段按钮**：按下的那个是实心朱红、白字，一眼看出选的是哪个；一组最多三个，永远一行，字太长就在按钮里折行。
- **课件面板（横屏侧栏）**：正文短时「上一步 / 下一步」紧跟正文，空白留在面板底下；正文长了才吸底。竖屏和手机翻页条一直在底部。
- 驾驶条放右下、不放底部正中：右下是原来方向键的位置，镜头避让 HUD 的逻辑（`world.hudInsets` 按卡片在左半还是右半来让）不用改；底部正中会挡住跟车视角里车的位置，里程表又在左下。

## 不动的

3D 场景、课文、交互逻辑。按钮的行为、键盘快捷键、无障碍名称、自测（`?selftest`）检查的 `data-control` 都没变；只换了外壳的 HTML 结构、CSS 和图标。
