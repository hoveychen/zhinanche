# 0016：上层箱的格子一格一格做旧

- **状态：** 已采纳（P21 甲块；数值可以再调）。
- **日期：** 2026-10-22
- **接着：** [0014](0014-lacquer-wear-stained-gears-cool-air.md)（车漆是用旧了的漆：磨边、积灰、漆面扫描，`wear()`）；[0013](0013-art-round-air-reds-light.md)（车站在光里）；[0006](0006-cad-level-chariot.md)（结构、尺寸、齿数不动）；[0004](0004-realtime-photo-look.md)（只做实时，取巧和烘焙）。

## 要求

第七轮复审 F1：「上层箱是一整面平的橙红格子，没有木纹，没有边缘高光，粗糙度也没有变化」。0014 给整车上了旧漆面之后，漆面不再荧光，但上层箱的格子仍然一格一格完全一样，塑料感只轻了一点。老板在最终汇报卡上选了这一项：全写实，「看起来就真的现实实拍一样的感觉」，只做实时，可以烘焙、拿空间换时间。

不动：格数、格距、格条的宽和厚、箱子的尺寸（0006）；齿数、传动比；下层箱的彩画格（0008）；0014 的漆色、磨边、积灰。

## 先量了什么

main（ad8fd7e），1440×900 鼠标 `?quality=high`、1024×768 触屏 `?quality=medium`，DPR 2，「自己开」默认机位（复审员的机位）。在截图上按格条的暗线定出受光面 12×3 格，每格取中间一半量 Lab：

- 格心平均 L 48.3、C 76.8：箱上最亮最纯的一块。
- **相邻格的平均差** ΔL 2.4、ΔC 2.7（去掉整面的光照渐变，只看格与格之间）：几乎一样。
- 原因：上层箱（重台）的格子是 `lattice()` 在一块 `lacquer` 板上贴的 `eave` 细条（宽 0.07、厚 0.05 尺，直角方条）。格心就是那块整板，一种颜色、一张漆面扫描一路铺过去；格条是方条，只有一个平面朝外，没有棱去接光。0014 的磨边和积灰来自 1024 见方的整车图集，一格只占几个 texel，分不出格。

## 改法

### A. 模型（`build_chariot.py`、`lib/mesh.py`）

- 上层箱四面的 `lattice()` 改用 `TIER_GRID`：格条换成新角色 `lattice_bar`，截面不变、四个角倒 0.016 尺（`MB.bar(chamfer=)`，八边形截面），棱上能接住一道光。
- 每格加一片格心 `lattice_cell`：离板面 0.004 尺的单面四边形（新的 `MB.quad()`），四边各压进格条下 0.01 尺。格心成了一格一个独立的面，着色器才能按格区分。
- 一开始格心做成 0.006 尺厚的薄盒，背光面有几格烘成全黑：薄盒埋在板里的背面和极窄的侧面在图集里烘得不对，压到了正面那一块。页面里把格心的 `aoMapIntensity` 设成 0 黑格就消失，确认是图集；改成单面四边形后重烘，黑格没了。同一原因，格心不取图集的 G（磨边）：单面片的边界在 Bevel 里整片都算成「边」，满格都是磨穿的斑点。
- `pnpm build:model` 重建、重烘。差动式 GLB 三角形 28470 → 29758（+1288，格条 1792、格心 264；原来的 `eave` 1788 → 1020），1.72 MB → 1.79 MB；宋史式 2.65 MB → 2.72 MB。图集 1024：340 KB → 342 KB。`pnpm check:model` CLEARANCE_OK。

### B. 着色器：按格的种子（`materials.js`）

- `latticeCells()`：加载时按位置把顶点焊成一块块（一片格心、一根格条），每块一个种子（块中心的哈希），格心还有自己的 0–1 横竖坐标，外加块中心在整面里的高度。写进顶点属性 `cellInfo`（vec4）。
- `wear()` 多一个参数 `cell`（1 格心、2 格条），配方是 `wear: [磨边, 积灰, 清漆发黄, cell]`。在 0014 的补丁后面接 `cellCoat()`：
  - **整面的渐变，不是拼色**：上排褪色（变浅、变灰、偏颜料的粉），下排沾路上的灰（暗一点、更糙）。只按格随机会成一块块拼色瓷砖（试过，像棋盘）。
  - **每格自己的漆**：明暗 0.8–1.1；约四成的格多褪一些；粗糙度 ×0.7–1.35；清漆强度 0.6–1，清漆粗糙度按褪色、积灰和种子加 0–0.6。
  - **薄漆透木**：约五格一格，顺木纹透出一点木色（0x9a6040，亮度和红漆相近；先试过直接压暗木纹，背光面那几格成了黑洞）。
  - **格边的积灰**：贴着格条一条细线暗 25%、更糙。先试过 0.16 宽的暗框，每格像一块枕形砖。
  - **掉漆**：约五格一格，在一条边的一段上掉到灰底（0x957257，暖灰褐；更冷的 0x6e5a48 在红底上看着发绿），没有清漆、更糙。哪条边、哪一段、多深都由种子定，形状来自漆面扫描 arm 图 B（沿木纹排过的剥落噪声），按格错开取样。
  - **开片**：约四成的格，在同一张噪声的等值线上画一像素宽的细暗线（沿木纹，像流水断）；线挤到一起时（远处）用 `fwidth` 淡掉，不在中远景闪成噪点。
  - 格条：同样的整面渐变和按根的明暗、光泽；磨边 0.8 → 0.4（倒角后图集在细条上烘出一串黑点）。
- 格心底色 0xb44a36（比箱板的 0xc8503a 暗一档、淡一点），格条 0x7a2a1f（比檐的 0x6c2117 亮一点，倒角的光才看得出来）：格框、格条、格心三层明暗分开。
- 0014 定的规矩照旧：补丁跟着 rig 克隆拷过去（`customProgramCacheKey` 带上 `cell`）；按模型坐标和种子取，不按世界坐标，车开起来花纹跟着车走；蓝、橙、黄和记号辐不受影响（只有两个新角色带 `cell`）。

## 结果

同机位、同档，before 是 main ad8fd7e，after 是本分支。受光面 12×3 格，每格取中间一半（1440 high「自己开」）：

| | before | after |
|---|---|---|
| 相邻格平均差 ΔL / ΔC | 2.4 / 2.7 | 4.6 / 5.3 |
| 格心平均 L | 48.3 | 42.5 |
| 格心平均 C | 76.8 | 61.4 |
| 格内 L 标准差 | 4.7 | 3.7 |

格与格之间的差翻了一倍，格心不再是整车最纯的红（C 低 15），平均 L 42.5 仍高于 0014 量的地面亮部 p90（37.7），0013 的「车站在光里」不受影响。格内的标准差低了一点：原来一格里最大的起伏是漆面扫描的大块光泽，现在叠在更暗的底色上；格内的细节（木纹、掉漆、开片）主要在近景看得到。

对照图在 `/tmp/zhinanche-polish/lattice/pairs/`：`free-desk.jpg`、`free-tab.jpg`（整屏），`crop-free-desk-box.jpg`、`crop-free-tab-box.jpg`（复审员机位的上层箱，原分辨率 ×1.5），`crop-close-desk-box.jpg`、`crop-close-desk-zoom2x.jpg`（「自己开」滚轮推到最近的上层箱近景）。透视、拆开、宋史式看齿轮、第一课第 1 步、首页逐张看过（`dbg/`），没有报错，透视和拆开时格子和箱子一起隐去。

## 帧率

1024×768 触屏、DPR 1、`?quality=medium` 或 `lite`（固定档位），解除 vsync（无头 Chrome、ANGLE Metal、Apple M4），main 与本分支交替、每轮换先后，各 3 次。这次机器上别的会话负载很高（测时 load 12–69），两边的绝对值都比 0014（约 2 ms）慢一倍，只看同一轮里的对比。原始数据 `/tmp/zhinanche-polish/lattice/fps.txt`。

| 场景 | 档 | main 中位（3 次） | 本分支中位（3 次） |
|---|---|---|---|
| 自由开，按住前进、每 1.5 s 交替左右拐、19.5 s | medium | 4.0 / 4.0 / 4.1 | 4.0 / 4.1 / 4.2 |
| 同上 | lite | 4.0 / 4.0 / 4.0 | 4.1 / 4.1 / 4.1 |
| 自己开推到上层箱近景、静置 10 s（格子占画面最多） | medium | 4.7 / 4.1 / 4.2 | 4.3 / 4.2 / 4.2 |
| 同上 | lite | 4.1 / 4.1 / 4.7 | 4.8 / 4.0 / 4.1 |

开车时中位多 0.07–0.1 ms，近景静置看不出差别（三次的中位两边都是 4.2 / 4.1，单次的起伏来自负载）。超过 33 ms 的帧两边都有，每次 0–1 帧（main 4 次、本分支 4 次，共 24 次测量），随负载出现。draw call 196 → 200（近景 192 → 196；两个新材质），三角形 +1288。格心和格条每个像素多两次贴图采样和几十条运算，只在这两种材质上。首页自动演示这次没测成：解除帧率上限后 main 和本分支的首页都偶尔卡在加载（只到 sky），同参数下两边一样，不是本分支引入的。

## 放弃的方案

- 只按格随机、不加整面渐变：一块块拼色，像棋盘。
- 格心用 0.006 尺薄盒：图集烘黑（见 A）。
- 给整块板单独展 UV、烘一张格子做旧图：要改烘焙流程、多一张图，而且一张图里每格的花样是固定的；种子加漆面扫描在着色器里做，没有新贴图。

## 还看得出假的地方

- 格条还是细，倒角只在受光的横条上读得出一道光；竖条和背光面基本还是一条暗线。要更明显得把格条加宽或加厚，那是改尺寸，这次没动。
- 开片在复审员机位和推到最近时都几乎看不到（按设计在远处淡掉）；「自己开」的镜头有最小距离，推不到能看清开片的近处。
- 格心与格条之间没有接触阴影：格条只高出 0.05 尺，阴影图分辨不出，只靠格边的积灰线。
- 下层箱的彩画格（0008）没动，格条仍是直角方条。
