# 3D 模型说明：齿轮布局、车轮、车身与自定尺寸

由 `blender/scripts/build_chariot.py` 生成；布局计算在 `blender/scripts/lib/layout.py`（纯 Python，`python3 blender/scripts/lib/layout.py --json` 把齿轮、啮合点、车轮和轴的坐标全部打出来）。坐标采用 Blender 车身坐标：+X 向前，+Y 向左，+Z 向上，单位为尺，原点在两车轮着地点连线的中点（地面）。glTF 坐标为 (x, z, −y)。每个尺寸的出处和置信度在 `params/chariot.json`，取舍在 [决策 0006](../design/decisions/0006-cad-level-chariot.md)。

**齿**都是径向的方截面硬木块齿（`params.gear`）：根宽 0.11、顶宽 0.06（四边倒角）、轴向厚 0.15（小平轮 0.2），齿顶超出节圆 0.15，轮辋外缘在节圆以内 0.2，齿根穿过轮辋在内侧露出 0.05 的榫头。齿距统一取宋史齿轮推出的 π×2.4/24 ≈ 0.314 尺（原文「齒間相去三寸」），所以各齿轮的节圆半径 = 齿数 × 0.314 / 2π。只有差速器内部（立齿圈和行星轮）用更小的齿：齿距 0.236，根宽 0.075、顶宽 0.045、厚 0.1。

燕肃车的齿另有两处改动，来自刚体物理复核（`research/physics/REPORT.md` §5.4、§7，取舍见[决策 0006](../design/decisions/0006-cad-level-chariot.md)「补」一节）：小平轮和大平轮的齿上下两面削成 45° 屋脊（`gear.toothRoofAngle`，截面六边形）；燕肃车所有齿的齿顶各边倒 45° 角 0.027 尺（`gear.toothTipChamfer`），立子轮的齿不削屋脊，四条长棱也倒同样大。这样小平轮落下时不会平面压平面地顶住。齿隙不变，差动式的齿不改。

**转向怎么保证**：`layout.mesh(g1, g2, 接触点, 传动比)` 先用几何算出 g2 的转角与 g1 的转角之比（含正负号），并断言它等于 `js/sim/chariot.js` 用的传动比，然后让 g2 的齿落进 g1 在接触点处的齿缝。只要有一处转向反了、半径不对，或者接触点不是两轮的公切点，构建就会失败。所有角度为 0 时，全部齿轮都处于啮合相位。

## 燕肃机构（宋史，1027）

| 部件 | 节点 | 齿数 | 节圆半径 | 中心 (x, y, z) | 转轴 |
|---|---|---|---|---|---|
| 车轮 | `wheel.L/R` | — | 3.0 | (0, ±3, 3) | +Y |
| 附足立子轮 | `song.foot.L/R` | 24 | 1.2 | (0, ±2.65, 3) | +Y（随车轮） |
| 小平轮 | `song.small.L/R` | 12 | 0.6 | (0, ±2.05, 4.2) | +Z |
| 中心大平轮 | `song.bigFlat` | 48 | 2.4 | (2.19, 0, 4.2) | +Z |
| 贯心轴 | `figure.shaft` | — | ⌀0.3 | x = 2.19，z 3.75 → 11.75（8 尺） | +Z |

- 立子轮套在车轮毂的内段上（「附足」）：毂从 y = 2.32 伸到 4.72，辐圈在 2.94，立子轮的中面在 2.65，轮辋径向宽 0.25，辐 4 根，毂套半径 0.64。它的最高点 (0, ±2.65, 4.2) 就是它和小平轮的啮合点。
- 小平轮是厚 0.2 的整块木盘，开方孔套在吊架的铁轴上，轴心在立子轮平面内侧 0.6 尺，用外沿咬立子轮的上沿，同时咬大平轮。
- 大平轮离两只小平轮的中心都是 2.4 + 0.6 = 3.0 尺。按勾股定理，它的中心只能放在车轴前方 x = √(3² − 2.05²) = 2.19 处：小平轮的切向速度必须和立子轮顶齿的运动方向（±X）一致，所以小平轮中心必须在 x = 0。这一点由几何决定，不是凭审美选的。大平轮轮辋径向宽 0.3、分 6 段，4 根通辐（8 臂），方毂套在立轴削方的一段上（0.3 见方）。
- 啮合时所有齿都在同一高度 z = 4.2（齿顶半径：立子轮 1.35，小平轮 0.75，大平轮 2.55）。离合抬起 0.4 尺后，小平轮在任何相位都碰不到立子轮和大平轮（干涉检查验证过）。
- **转向**（转左弯为例）：右轮向前滚，绕 +Y 转 φ，立子轮顶齿向前（+X）走。右小平轮在立子轮顶的内侧，被带着逆时针（俯视）转 2φ，对应 `smallR = +2·footR`。大平轮与小平轮是外啮合，反转 −φ/2，对应 `bigFlat = −smallR/4`。原地绕左轮转 90° 时，右轮转半圈：立子轮走 12 齿，右小平轮转一圈，大平轮反转四分之一圈。这正是原文「附右足子輪順轉十二齒，擊右小平輪一匝，觸中心大平輪……四分之一」。左侧镜像，`smallL = −2·footL`。
- 离合示意：`song.smallLift.L/R` 包含小平轮的铁轴、竹绳和铁坠，绳子垂到辕尾横木上方。`song.roller.L/R` 是辕端横木下的小轮（⌀0.3，原文尺寸），离合时一起升降 0.2 尺。这部分只表示联动关系，不是考据结果。
- 立轴：⌀0.3，下端铁尖坐在两根纵梁之间横木上的铁臼里（z 3.75），装大平轮处削方，上端套铁箍，顶上莲座托木人。

## 差动机构（Lanchester 式推测，非宋史原文）

| 部件 | 节点 | 齿数 | 节圆半径 | 中心 (x, y, z) | 转轴 | 和谁啮合 |
|---|---|---|---|---|---|---|
| 左立轮（冠轮） | `diff.crown.L` | 42 | 2.1 | (0, 2.1, 3) | +Y（随左轮） | 用下沿咬 sideA |
| 左水平轮 + 下侧齿圈 | `diff.sideA` | 42 + 16 立齿 | 2.1 / 0.6 | (0, 0, 0.9) | +Z | 冠轮 L、两个行星轮 |
| 右立轮（冠轮） | `diff.crown.R` | 18 | 0.9 | (0, −0.9, 3) | +Y（随右轮） | 用下沿咬 sideB |
| 右水平轮 + 上侧齿圈 | `diff.sideB` | 18 + 16 立齿 | 0.9 / 0.6 | (0, 0, 2.1) | +Z | 冠轮 R、两个行星轮 |
| 行星架 | `diff.carrier` | — | 臂长 0.6 | (0, 0, 1.5) | +Z | 固定在贯心轴上 |
| 行星小轮 | `diff.pinion.0/1` | 8 | 0.3 | (±0.6, 0, 1.5) | ±X（各自朝外） | sideA 立齿（下）、sideB 立齿（上） |
| 贯心轴 | `figure.shaft` | — | ⌀0.3 | x = 0，z 0.55 → 11.75 | +Z | — |

- **传动比由齿数算出**：`js/sim/params.js` 的 `DIFF.inputRatio = crownLeftTeeth / flatLeftTeeth`（右边同样，并断言相等），`layout.py` 再断言它等于轮径 ÷ 轮距。每个冠轮与它驱动的水平轮齿数相同、齿距相同，半径也就相同，所以传动比恰好为 1。
- **为什么用下沿**：车轮向前滚时，冠轮的上沿向前、下沿向后。左冠轮在水平轮的 +Y 侧，下沿向后推，水平轮就逆时针转，得到 `sideA = +wheelL`；如果用上沿，转向就反了。右冠轮在 −Y 侧，下沿向后推，水平轮顺时针转，得到 `sideB = −wheelR`。两个水平轮都在车轴下方，所以车轮装在各自转动的半轴上（`diff.crown.L/R` 节点里，各带軎、辖），轴承是车架上的伏兔。半轴不贯通车身中线，让出中间给竖轴。
- **为什么两侧大小不同、高度错开**：冠轮半径等于水平轮半径，啮合高度就是 z = 3 − R。两侧如果一样大，两个水平轮会挤在同一高度、同一位置。左侧取大（R = 2.1，z = 0.9），右侧取小（R = 0.9，z = 2.1），两层之间留出 1.2 尺放差速器。左冠轮中面在 y = 2.1，齿厚 0.15，离毂内端 2.32 和齿轮室侧板内面 2.28 都只有 0.1 左右，这是左轮能取到的最大半径（`layout.py` 有断言）。
- **差速器**：下侧齿圈 A 的 16 根立齿朝上，上侧齿圈 B 的 16 根立齿朝下。两个 8 齿行星轮立在行星架两臂上，下沿咬 A、上沿咬 B。行星架转角 = (sideA + sideB)/2，行星轮自转 = (sideA − sideB)/2 × 16/8，与 `chariot.js` 一致。两只行星轮相隔 180°，16 齿正好是对称的，所以两只都能同时啮合（构建时有断言）。
- 差速器部分偏小（行星轮直径 0.6 尺），课件里可以用标注或近景镜头把它放大。

## 车身与辕（`params.body`）

- **布局**按《大驾卤簿图书》的指南车：下层齿轮室在两轮之间（侧板外面 |y| = 2.28，`widthBetweenWheels` 4.56，要在毂内端 2.32 以内；板从 z 1.05 到 3.55），上面是红色高箱罩住车轮上半圈（阔 9.5，`boxWidth`，借吴德仁车「闊九尺五寸」；箱底 3.55 略高于轴心，箱顶 7.6；箱板上画方格）。箱的前后长借吴德仁「深一丈九寸」10.9：燕肃车 x −4.02 → 6.88（大平轮中心前后 0.57 : 0.43），差动车 ±5.45。齿轮室长 8：燕肃车 x −3 → 5，差动车 ±4（`body.length`）。
- 箱顶第一层檐（出 0.35），其上重台：上层箱体（四面各缩 0.6 / 0.65，高 7.9 → 10.3，画方格），镂拱带（10.3 → 10.8，一圈拱块与空当），第二层檐（出 0.45，到 11.1），顶台（11.1，勾阑高 0.7 到 11.9），四角挑杆挂香囊。贯心轴顶 11.75（`model.shaftTopHeight`），木人站在莲座上。吴德仁车「身一丈一尺一寸五分」若指车高，顶台勾阑上沿就在它附近。
- 齿轮室顶板（`body.deck`）在 5.6（`model.deckHeight`），在箱内，大平轮（z 4.2，齿顶半径 2.55）在它下面、箱内，所以侧板不再需要开槽；燕肃车侧板在车轴处开窗，箱底板在立子轮处开口。
- **辕**：单辕，长 10.5（借吴德仁），后端 ⌀0.35 渐收到颈 ⌀0.23（考工记辀人的比例），舆下平直（z 3.35），出箱后上扬 12°；辕端横木（衡）长 6（考工记「三稱」）、⌀0.4，绳缚在辕上，两根轭钉；辕头凤首。燕肃车辕从 x −1 起，尾端上方 x 4.35 处的横木（高 3.95）是离合吊绳的落点，横木下两个辕端小轮。差动车辕从立轴前 0.3 起。
- shell 组（侧板、前后板、顶板、重台、顶台）的 explode 偏移是往外或往上拉开（拆开时它们边飞边淡出，不进取景）：侧板 ±5.5，前后板 ±4，顶板 ↑4.5，重台 ↑5.5，顶台 ↑6.5；车轮向外 ±3.4；齿轮按层往上分开、不往地下走：差动式 sideA 不动、架子 ↑1.1、sideB ↑2.2，冠轮随所咬的水平轮一起移动并向外 ±1.4；燕肃车立子轮 ±1.4 向外，小平轮吊架 ↑1.0、向外 0.5，大平轮 ↑2.0；竖轴 ↑1.7（差动）/ ↑2.6（燕肃），木人比竖轴多抬 1 尺，留在画面里。飞出的先后次序在 js/scene/rig.js 的 STAGES。

## 干涉检查、啮合检查与已知问题

`pnpm check:model` 的流程：先用 `tools/export-poses.mjs` 跑 `scenarios.js` 里全部路线、3 条随机路线、一条手绘路线，再从静止开始逐步跑三条（左绕轮 90°、右绕轮 90°、直行 20 尺），共约 9000 个姿态。然后导入**交付的 GLB**，先对每个啮合对打印一行 `GEAR`（节圆是否相切、互相咬入多深、齿顶离对方轮辋多远、齿侧间隙多大，任一项不够就 FAIL），再对所有能相对运动的网格对做三角形相交检查。轴承、键连接、木人与轴这类设计接触在白名单里。燕肃车最紧的齿侧间隙 0.025 尺（约 8 mm；加齿顶倒角之前是 0.010）：方块齿不是渐开线，12 齿的小平轮齿槽向根部收窄得快，齿根宽只能取到 0.11。

**燕肃车离合落下时的齿相位**：小平轮抬着时不转，立子轮却始终跟着车轮转，所以一段直行之后再放下小平轮，它的齿一般对不准齿缝。仿真在放下的那一步对齿（`js/sim/chariot.js` 的 `#engage`，[决策 0007](../design/decisions/0007-song-clutch-error.md)）：先把小平轮转到最近的立子轮齿缝，满足 `small ∓ 2·foot ≡ 0 (mod 30°)`（最多 15°）；再把大平轮连同木人推到最近的齿槽，满足 `small + 4·bigFlat ≡ 0 (mod 30°)`（最多 3.75°）。这一推就是网页里宋史式的入齿误差。因此导出的每个放下姿态都在相位上，干涉检查对它们全部测试；万一出现相位不对的放下姿态，记 `PHASE … FAIL`（以前记 WARN、跳过不测）。
