# 3D 模型说明：齿轮布局与自定尺寸

由 `blender/scripts/build_chariot.py` 生成；布局计算在 `blender/scripts/lib/layout.py`（纯 Python）。坐标采用 Blender 车身坐标：+X 向前，+Y 向左，+Z 向上，单位为尺，原点在两车轮着地点连线的中点（地面）。glTF 坐标为 (x, z, −y)。

所有齿都是木销。齿距统一取宋史齿轮推出的 π×2.4/24 ≈ 0.314 尺（原文「齒間相去三寸」），所以各齿轮的节圆半径 = 齿数 × 0.314 / 2π。只有差速器内部用了更小的齿距 0.236 尺。

**转向怎么保证**：`layout.mesh(g1, g2, 接触点, 传动比)` 先用几何算出 g2 的转角与 g1 的转角之比（含正负号），并断言它等于 `js/sim/chariot.js` 用的传动比，然后让 g2 的木销落进 g1 在接触点处的齿缝。只要有一处转向反了、半径不对，或者接触点不是两轮的公切点，构建就会失败。所有角度为 0 时，全部齿轮都处于啮合相位。

## 燕肃机构（宋史，1027）

| 部件 | 节点 | 齿数 | 节圆半径 | 中心 (x, y, z) | 转轴 |
|---|---|---|---|---|---|
| 车轮 | `wheel.L/R` | — | 3.0 | (0, ±3, 3) | +Y |
| 附足立子轮 | `song.foot.L/R` | 24 | 1.2 | (0, ±2.65, 3) | +Y（随车轮） |
| 小平轮 | `song.small.L/R` | 12 | 0.6 | (0, ±2.05, 4.2) | +Z |
| 中心大平轮 | `song.bigFlat` | 48 | 2.4 | (2.19, 0, 4.2) | +Z |
| 贯心轴 | `figure.shaft` | — | ⌀0.3 | x = 2.19，z 3.75 → 11.75（8 尺） | +Z |

- 立子轮立着装在车轮内侧，它的最高点 (0, ±2.65, 4.2) 就是它和小平轮的啮合点。
- 小平轮水平放置，轴心在立子轮平面内侧 0.6 尺，用外沿咬立子轮的上沿，同时咬大平轮。
- 大平轮离两只小平轮的中心都是 2.4 + 0.6 = 3.0 尺。按勾股定理，它的中心只能放在车轴前方 x = √(3² − 2.05²) = 2.19 处：小平轮的切向速度必须和立子轮顶齿的运动方向（±X）一致，所以小平轮中心必须在 x = 0。这一点由几何决定，不是凭审美选的。
- 啮合时所有木销都在同一高度 z = 4.2。离合抬起 0.4 尺后，小平轮在任何相位都碰不到立子轮和大平轮（干涉检查验证过）。
- **转向**（转左弯为例）：右轮向前滚，绕 +Y 转 φ，立子轮顶齿向前（+X）走。右小平轮在立子轮顶的内侧，被带着逆时针（俯视）转 2φ，对应 `smallR = +2·footR`。大平轮与小平轮是外啮合，反转 −φ/2，对应 `bigFlat = −smallR/4`。原地绕左轮转 90° 时，右轮转半圈：立子轮走 12 齿，右小平轮转一圈，大平轮反转四分之一圈。这正是原文「附右足子輪順轉十二齒，擊右小平輪一匝，觸中心大平輪……四分之一」。左侧镜像，`smallL = −2·footL`。
- 离合示意：`song.smallLift.L/R` 包含小平轮的铁轴、竹绳和铁坠，绳子垂到辕尾横木上方。`song.roller.L/R` 是辕端横木下的小轮（⌀0.3，原文尺寸），离合时一起升降 0.2 尺。这部分只表示联动关系，不是考据结果。
- 大平轮连齿半径 2.51 尺，比车厢半宽 2.3 尺还宽，所以两侧车厢板在 z = 4.2 处开了一道槽，大平轮的齿从槽里露出来。两侧板在小平轮的位置也开了窗。

## 差动机构（Lanchester 式推测，非宋史原文）

| 部件 | 节点 | 齿数 | 节圆半径 | 中心 (x, y, z) | 转轴 | 和谁啮合 |
|---|---|---|---|---|---|---|
| 左立轮（冠轮） | `diff.crown.L` | 42 | 2.1 | (0, 2.1, 3) | +Y（随左轮） | 用下沿咬 sideA |
| 左水平轮 + 下侧齿轮 | `diff.sideA` | 42 + 16 立销 | 2.1 / 0.6 | (0, 0, 0.9) | +Z | 冠轮 L、两个行星轮 |
| 右立轮（冠轮） | `diff.crown.R` | 18 | 0.9 | (0, −0.9, 3) | +Y（随右轮） | 用下沿咬 sideB |
| 右水平轮 + 上侧齿轮 | `diff.sideB` | 18 + 16 立销 | 0.9 / 0.6 | (0, 0, 2.1) | +Z | 冠轮 R、两个行星轮 |
| 行星架 | `diff.carrier` | — | 臂长 0.6 | (0, 0, 1.5) | +Z | 固定在贯心轴上 |
| 行星小轮 | `diff.pinion.0/1` | 8 | 0.3 | (±0.6, 0, 1.5) | ±X（各自朝外） | sideA 立销（下）、sideB 立销（上） |
| 贯心轴 | `figure.shaft` | — | ⌀0.3 | x = 0，z 0.55 → 11.75 | +Z | — |

- **传动比恰好为 1**：每个冠轮与它驱动的水平轮齿数相同、齿距相同，半径也就相同。
- **为什么用下沿**：车轮向前滚时，冠轮的上沿向前、下沿向后。左冠轮在水平轮的 +Y 侧，下沿向后推，水平轮就逆时针转，得到 `sideA = +wheelL`；如果用上沿，转向就反了。右冠轮在 −Y 侧，下沿向后推，水平轮顺时针转，得到 `sideB = −wheelR`。两个水平轮都在车轴下方，所以车轮装在各自转动的半轴上，轴承在车架的两根纵梁上。半轴不贯通车身中线，让出中间给竖轴。
- **为什么两侧大小不同、高度错开**：冠轮半径等于水平轮半径，啮合高度就是 z = 3 − R。两侧如果一样大，两个水平轮会挤在同一高度、同一位置。左侧取大（R = 2.1，z = 0.9），右侧取小（R = 0.9，z = 2.1），两层之间留出 1.2 尺放差速器。左冠轮在 y = 2.1 处，离侧板内面只有 0.07 尺，这是左轮能取到的最大半径。
- **差速器**：下侧齿轮 A 的 16 根立销朝上，上侧齿轮 B 的 16 根立销朝下。两个 8 齿行星轮立在行星架两臂上，下沿咬 A、上沿咬 B。行星架转角 = (sideA + sideB)/2，行星轮自转 = (sideA − sideB)/2 × 16/8，与 `chariot.js` 一致。两只行星轮相隔 180°，16 齿正好是对称的，所以两只都能同时啮合（构建时有断言）。
- 差速器部分偏小（行星轮直径 0.6 尺），课件里可以用标注或近景镜头把它放大。

## 车身（自定，只为好看和清楚）

- 齿轮室：燕肃车长度 x −3 → 5，差动车 x −4 → 4（长 8 尺，取自 `body.length`）。侧板外面在 |y| = 2.3（`widthBetweenWheels`）。纵梁在 z 2.85–3.15。下层平台高 5.6 尺（`model.deckHeight`），四周有勾闌。
- 上层重台以贯心轴为中心，面积 3.8 × 3.4，上有勾闌和四根红柱，柱顶 9.0 尺，屋顶为攒尖顶，顶点 10.4 尺。贯心轴穿出屋顶，木人站在 11.75 尺处（`model.shaftTopHeight`）。
- 车辕长 10.5 尺（借用吴德仁车「車轅一丈五寸」），离地 3.45 尺，前端有横木。
- shell 组（侧板、前后板、平台、重台、屋顶）的 explode 偏移是往外或往上拉开（拆开时它们边飞边淡出，不进取景）；车轮向外 ±2.8；齿轮按层往上分开、不往地下走：差动式 sideA 不动、架子 ↑1.1、sideB ↑2.2，冠轮随所咬的水平轮一起移动并向外 ±1.4；燕肃车立子轮 ±1.4 向外，小平轮吊架 ↑1.0、向外 0.5，大平轮 ↑2.0；竖轴 ↑1.7（差动）/ ↑2.6（燕肃），木人比竖轴多抬 1 尺，留在画面里。飞出的先后次序在 js/scene/rig.js 的 STAGES。

## 干涉检查与已知问题

`pnpm check:model` 的流程：先用 `tools/export-poses.mjs` 跑 `scenarios.js` 里全部路线、3 条随机路线、一条手绘路线，再从静止开始逐步跑三条（左绕轮 90°、右绕轮 90°、直行 20 尺），共约 9000 个姿态。然后导入**交付的 GLB**，对所有能相对运动的网格对做三角形相交检查。轴承、键连接、木人与轴这类设计接触在白名单里。

**燕肃车离合落下时的齿相位**：仿真里小平轮只在放下时才累计转角，立子轮却始终跟着车轮转。所以一段直行之后再放下小平轮，它的木销通常对不准立子轮或大平轮的齿缝。干涉检查只在相位一致的姿态（从静止开始的转弯，以及所有抬起状态）里测试这些啮合对，相位不对的姿态记为 WARN（约 1400–4500 个）。用 `--all-phases` 强制检查时，这些姿态会出现真实穿模。建议场景在小平轮落下的瞬间把它的显示角度对齐到最近的啮合相位：先满足和立子轮的相位关系 `small ∓ 2·foot ≡ 0 (mod 30°)`。这样它和大平轮之间还会有最多半个齿的错位，要完全消除，就得在仿真里给离合加「对齿」过程。
